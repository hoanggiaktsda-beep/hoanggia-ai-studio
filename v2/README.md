# HOANGGIA AI — Studio V2

Phiên bản V2 của HOANGGIA AI Studio, phát triển theo workflow của các AI visualization workspace hiện đại, với trọng tâm là **Design Intelligence** cho kiến trúc và nội thất.

## Workflow

**Analyze → Design Intent → Design Intelligence → Master Prompt → Render → Edit → Camera → Concept → Multi-view Sync**

### Điểm cốt lõi
- MASTER image là nguồn sự thật.
- Reference chỉ định hướng style/material/form khi được yêu cầu.
- Preservation Locks giúp giảm geometry drift.
- Một Design State dùng chung cho Render / Edit / Camera / Sync.
- Master Prompt được suy luận từ công năng, tỷ lệ, nhân trắc, vật liệu, ánh sáng và camera.
